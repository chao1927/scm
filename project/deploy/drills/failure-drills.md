# 非破坏性故障演练清单

| 场景 | 测试环境注入方式 | 期望行为 | 退出与恢复 |
| --- | --- | --- | --- |
| RocketMQ 积压 | 暂停一个测试 Consumer，不删除消息 | Outbox/消费延迟告警；生产者不伪成功 | 恢复 Consumer，确认积压下降和 Inbox 幂等 |
| 外部接口超时 | 将测试依赖指向可控延迟端点 | 超时、退避重试、熔断，业务状态可解释 | 恢复地址，触发安全重试并核对审计 |
| Redis 不可用 | 仅停止测试 Redis | IAM 缓存失败不绕过权限，readiness 反映依赖 | 恢复 Redis，验证 Token/MFA 会话一致性 |
| Dubbo Provider 下线 | 停止测试 WMS Provider | Consumer 快速失败，不生成虚假引用号 | 重启 Provider，验证 Nacos 重发现与同幂等键复用 |
| MySQL 只读 | 使用隔离只读账号启动单服务 | 写命令失败且事务回滚，查询保持可用或明确降级 | 切回读写账号，校验无半成品和 Outbox 一致 |
| 连接耗尽 | 在测试库使用受控低连接上限 | p99/连接池告警，服务不无限等待 | 结束占用连接，确认池恢复和请求成功 |

每次演练必须记录开始/结束时间、影响服务、指标截图、恢复证据和遗留问题。未经环境负责人批准，不得在生产执行注入。
