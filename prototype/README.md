# 供应链九大子系统统一交互原型

本原型依据 `docs/04-子系统功能设计` 下的 9 份产品功能设计构建，采用业务人员熟悉的统一后台结构：

```text
子系统工作台
└── 业务列表
    └── 业务详情
```

这是用于验证信息架构和业务交互的可丢弃原型，不连接真实后端，也不作为生产代码。

## 一键启动

```bash
./prototype/serve.sh
```

默认地址：<http://127.0.0.1:4173>

指定端口：

```bash
./prototype/serve.sh 8080
```

## 页面结构

### 1. 工作台

工作台负责发现问题和进入业务，不承担复杂操作：

- 关键业务指标
- 我的待办
- 风险与异常
- 关键流程进度
- 常用功能入口

### 2. 业务列表

各模块采用一致的列表交互：

- 状态及数量快捷筛选
- 编号、对象、负责人和状态查询
- 数据范围与风险条件
- 批量选择、导出和分页
- 点击业务编号进入详情

### 3. 业务详情

一个业务对象的完整信息集中在详情页：

| 页签 | 内容 |
| --- | --- |
| 基本信息 | 编号、主体、数据范围、状态、负责人、风险和版本 |
| 明细信息 | 商品、费用或业务行的计划量、完成量和差异 |
| 履约跟踪 | 数量、时效及生命周期进度 |
| 关联单据 | 上游需求、下游执行、库存或费用事实 |
| 流程记录 | 状态机节点与审批过程 |
| 操作日志 | 人员和系统操作的审计轨迹 |
| 领域事件 | 面向技术支持的事件编号、Outbox 和幂等结果 |

## URL 参数

```text
?system=purchase&page=orders&view=list
?system=purchase&page=orders&view=detail&record=PO20260727021&tab=process
```

| 参数 | 说明 |
| --- | --- |
| `system` | 当前子系统 |
| `page` | 当前功能菜单 |
| `view` | `workbench`、`list` 或 `detail` |
| `record` | 详情页业务对象编号 |
| `tab` | 详情页签 |

原来的 `variant=A|B|C` 参数和底部方案切换器已经删除。

## 交互与领域约束

- 写操作会先展示业务命令、目标对象、预期状态变化和后续记录。
- 确认后仅更新浏览器内存状态，并写入操作日志；刷新页面即恢复。
- 当前子系统只展示其拥有的数据，跨系统协作通过领域事件表达。
- 领域事件页签可按实际权限仅对技术支持、审计或管理员开放。
- 支持桌面、平板和移动端，移动端通过顶部按钮展开功能菜单。
