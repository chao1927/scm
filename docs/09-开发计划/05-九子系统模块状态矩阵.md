# 九子系统模块状态矩阵

## 1. 盘点方法

本矩阵同时检查以下证据：

1. `需求单/` 中的 64 张正式需求；
2. `01-开发计划/` 中九个子系统的接口级计划；
3. `02-开发日志.md` 中的实现、迁移、接口、事件和测试记录；
4. 当前九个 Maven 服务、前端资源定义和一键运行边界；
5. `ARCH-REQ-001` 对独立集成服务、报表服务的迁移决定。

状态以当前仓库事实为准。历史日志中已经被后续架构决策替代的结论不作为当前边界。
