## 2. 统一状态口径

| 状态 | 含义 | 是否可领取 |
| --- | --- | --- |
| 已完成 | 仓库内验收项有代码、测试和开发日志证据 | 否，仅允许缺陷修复 |
| 部分完成 | 已有可运行切片，但需求仍存在未通过的验收项 | 是，领取剩余切片 |
| 待开发 | 依赖已经具备，尚无完成证据 | 是 |
| 阻塞 | 缺少外部地址、凭证、环境、测试数据或业务决策 | 否，先解除阻塞 |
| 已迁移 | 原能力已迁入九个事实拥有者，旧服务/页面不得恢复 | 否 |
| 已撤销 | 原方案不再成立，仅保留历史记录 | 否 |

“接口首轮完成”只说明仓库内纵向切片存在，不等于生产可用。生产完成仍需真实中间件、外部系统、容量、监控、备份恢复和上线演练。

## 4. 九子系统边界

| 子系统 | 限界上下文 | 事实主权 |
| --- | --- | --- |
| 供应商 | 供应商协同 | 准入、资质、供货条件、供应商确认、ASN 协同、绩效 |
| 采购 | 采购执行 | 请购、询价、比价定标、采购价格、采购订单、退供 |
| WMS | 仓储作业 | 收货、质检、上架、库内作业、出库、退货、盘点 |
| 中央库存 | 库存可用性 | 库存账户、数量桶、流水、预占、调拨、快照与对账 |
| OMS | 订单履约 | 渠道订单、销售订单、履约、取消和售后策略 |
| TMS | 运输履约 | 运输任务、运单、面单、轨迹、签收、运输异常与费用来源 |
| BMS | 计费结算 | 费用、调整、对账、账单、发票、财务交接与退款 |
| 主数据 | 主数据治理 | 类型、模板、编码、记录版本、发布订阅与数据质量 |

跨子系统动作使用命令请求，结果使用领域事件表达。Outbox、Inbox、重试、熔断、失败查询和人工重放归生产者或消费者自己维护，不再恢复独立集成服务；报表和导出归业务事实拥有者。

## 5. 多 Agent 使用规则

1. 一个 Agent 一次只领取一个 `NEXT` 任务，且只能修改任务声明的文件范围。
2. 涉及共享契约时，先由契约 Agent 固化 API、事件、迁移编号和权限码，再允许下游并行。
3. 同一 Maven 服务、同一 Flyway 目录、同一前端资源注册文件同一时间只能有一个写入者。
4. 每个 Agent 必须完成领域、应用、接口、持久化、Outbox/Inbox、测试和日志，不得以空实现或仅建表宣称完成。
5. 合并前执行任务级测试；每批次结束后执行九服务全量测试、P3C、前端单测/构建/E2E。
