# PUR-REQ-001 采购核心业务需求基线

> 状态：部分完成。现有代码覆盖主要能力，需按本基线完成追踪和回归验收。

## 1. 业务目标

建立从请购、询价、比价定标、采购价格到采购订单、到货跟踪和退供的采购执行闭环。

## 2. 范围与不变量

| 能力 | 核心聚合 | 关键不变量 |
| --- | --- | --- |
| 请购与审批 | 请购单 | 已转采购数量不得超过批准数量；审批后锁定批准口径 |
| RFQ | 询价单 | 发布后邀请范围和询价行不可直接覆盖；截标后拒绝报价 |
| 比价定标 | 比价单 | 比较快照不可变；定标必须引用有效报价 |
| 采购价格 | 采购价格 | 同供应商、SKU、组织和适用范围的生效期不得冲突 |
| 采购订单 | PO、PO 变更 | 发布前校验供应商、合同、价格；变更保留版本；取消受 ASN/收货约束 |
| 到货与退供 | 到货跟踪、退供申请 | 到货事实来自 WMS；退供数量不得超过可退数量 |

## 3. 跨上下文规则

- 主数据提供 SKU、组织、税率等有效版本；供应商提供准入、供货和报价协同事实。
- WMS 拥有收货、质检和上架事实；采购只维护采购执行投影。
- BMS 拥有应付计费和财务事实；采购只提供订单金额和退供业务依据。

## 4. 验收

- 重复请购、超批准转单、截标后报价、价格重叠、PO 并发变更、已收货取消和超量退供有自动化测试。
