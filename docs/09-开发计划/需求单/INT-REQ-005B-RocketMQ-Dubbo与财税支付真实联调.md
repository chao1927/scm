# INT-REQ-005B RocketMQ、Dubbo 与财税支付真实联调

## 目标

在真实中间件和外部沙箱中验证集成中心已实现的通道契约、鉴权、超时、重试、熔断、幂等、回执和人工补偿能力。

## 外部前置条件

| 范围 | 必需输入 |
| --- | --- |
| RocketMQ | nameserver、Topic/Tag、ACL、生产/消费组、网络白名单 |
| Dubbo | Nacos/注册中心、接口/方法/参数类型、版本/分组、应用凭证 |
| ERP/税务/支付 | 沙箱地址、客户端凭证、签名/验签材料、回调地址、样例载荷与错误码 |
| 测试 | 可重复业务数据、对账基准、故障注入窗口和外部联系人 |

## 验收

- 真实生产、消费与泛化调用成功，重复消息不产生重复副作用。
- 超时、失败、熔断恢复、死信/最终失败和人工重放有证据。
- 财税支付签名、回调幂等、状态对账和异常补偿通过。
- 契约测试、链路追踪和开发日志完成。
