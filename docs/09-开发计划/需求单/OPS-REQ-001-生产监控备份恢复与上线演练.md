# OPS-REQ-001 生产监控、备份恢复与上线演练

## 目标

完成供应链系统上线前的可观测性、容量、故障恢复、数据保护和发布回滚验收。

## 范围

- 服务、数据库、Redis、RocketMQ、Dubbo/Nacos 指标、日志、Trace 和告警。
- 核心下单、预占、出入库、运输、结算链路压测与容量基线。
- 服务降级、中间件中断、消息积压、外部沙箱超时和数据库故障演练。
- MySQL 备份、时间点恢复、Outbox/Inbox 对账恢复和 RTO/RPO 验证。
- 灰度发布、配置回滚、数据库迁移回退/前滚和上线检查表。

## 验收

- 监控看板、告警规则、值班路由和运行手册可用。
- 压测达到目标吞吐且错误率、延迟和资源水位符合阈值。
- 故障演练不破坏数量/金额/库存不变量，恢复后可对账。
- 备份恢复达到约定 RTO/RPO，发布和回滚演练通过。

## 当前状态

`阻塞`。需要可运行集成/生产预演环境、真实中间件、测试数据、监控平台和告警通道。
