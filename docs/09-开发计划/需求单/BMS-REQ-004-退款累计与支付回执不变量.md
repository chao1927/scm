# BMS-REQ-004 退款累计与支付回执不变量

## 1. 目标

防止同一账单多笔退款累计超额，保证支付回执幂等，并为支付失败提供可审计重试入口。

## 2. 规则

1. 创建退款时锁定账单，`本次退款 <= 账单金额 - 已请求/已完成退款累计`。
2. 失败退款不继续占用可退金额；请求中和已完成退款占用额度。
3. 支付回执号全局唯一；同回执号+退款号重复返回当前结果，回执号绑定其他退款时拒绝。
4. 只有失败退款可重试，重试清除失败原因并回到请求中；已完成退款不可重试。
5. 成功/失败回执、退款状态和 Outbox 在同一事务完成。

## 3. 接口

- `POST /openapi/bms/v1/refund-settlements/{refundNo}/receipts`
- `POST /api/bms/v1/refund-settlements/{refundNo}/retry`

## 4. 数据

`bms_refund_receipt` 以 `receipt_no` 唯一，保存退款号、回执状态和原始载荷；退款累计查询仅统计状态 1/2。
