# REV-REQ-003 WMS 退货质检与库存处置

## 1. 目标

消费 OMS 退货入库命令，完成 WMS 实收、五类质检和中央库存处置，保证库存数量守恒且异常品不误入可售库存。

## 2. 交付范围

| 上下文 | 交付 |
| --- | --- |
| WMS | 退货作业聚合、持久化、收货/质检/详情接口；OMS 命令 Inbox；`ReturnReceived/ReturnInspected` Outbox |
| 中央库存 | 退货处置子账、WMS 事件 Inbox；良品入可用，残次/冻结入冻结账，报废/无单仅记处置事实 |

## 3. 验收规则

1. 实收量大于 0 且不超过应收量。
2. `良品 + 残次 + 冻结 + 报废 + 无单异常 = 实收量`，各项不得为负。
3. 无单异常大于 0 时 WMS 进入异常状态，OMS 进入异常待处理。
4. 中央库存以 WMS 事件号幂等；良品增加可用和实物，残次/冻结增加实物并冻结，报废/无单不增加可用。
5. 内部入口校验 JWT 应用身份与声明来源一致；写操作校验仓库数据范围。

## 4. 补偿

WMS/库存处理失败保留 Inbox 失败记录并可重放；库存处置表以来源事件唯一键防止重复回补。人工修正必须产生新质检事件，不覆盖已消费事实。
